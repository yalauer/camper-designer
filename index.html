Vorlagen

Möbel

Shift-/Strg-Klick markiert mehrere Boxen. Verbundene Boxen bewegen sich gemeinsam.

Auswahl bearbeiten

Breite und Höhe: 0 = so groß wie die Box — der Versatz wirkt dann nicht. Sonst positionieren die beiden Versatz-Maße den Auszug auf seiner Fläche, gemessen ab der unteren bzw. linken Kante der Box (quer = Fahrerseite → Schiebetür bzw. Front → Heck).

Filter

Ein Filter markiert Möbel quer durchs ganze Fahrzeug. Das Häkchen links schaltet jeden Filter einzeln zu — mehrere gleichzeitig sind möglich. Sichtbar bleibt, was zu mindestens einem aktiven Filter gehört; alles andere wird transparent. Zuordnung im Panel „Auswahl bearbeiten“ bzw. „Sitzbank“.

Plan speichern

Bedienung:
Klick = Box auswählen · Ziehen = verschieben
Shift-/Strg-Klick = mehrere Boxen markieren (zum Verbinden)
In Iso-Ansicht: Ziehen = auf Boden, Shift+Ziehen = Höhe
Pfeiltasten = schrittweise (Alt = 1 mm fein)
Mausrad = Zoom · Rechte Maustaste = Ansicht verschieben
Entf = Box löschen · R = um 90° drehen
Strg+Z / Strg+Y = Rückgängig / Wiederholen
Draufsicht = Blick von oben (Schiebetür oben, Fahrerseite unten).
Snap: Boxen rasten an Wänden/Nachbarn ein (Alt beim Ziehen = aus).
Gewicht/Maße: Schalter in der Kopfzeile. Maße erscheinen nur für die ausgewählte Box — blau = Abstand zur Nachbarbox, grün = Abstand zur Innenwand.
Auszug: Häkchen an der Box → der Freiraum beim Öffnen wird gestrichelt eingeblendet (Richtung, Tiefe, Breite und Höhe einstellbar).
Filter: Im Panel „Filter" beliebig viele Kategorien anlegen (Strom, Wasser, Gas …), Möbel im Bearbeiten-Panel zuordnen. Der aktive Filter lässt nur die zugeordneten Möbel voll sichtbar; „⚡ Filter" in der Kopfzeile schaltet ihn schnell aus und wieder ein.
Sitzbank: Schnierle SL3 auf 1250-mm-Bodenschienen. Ziehen = Bank auf der Schiene, Shift+Ziehen = Schienen im Boden.
Subtraktion: Häkchen setzen → die Box schneidet ihr Schnittvolumen aus anderen Boxen (und aus Radkästen) heraus.
Verbinden: Mehrere Boxen markieren → „⛓ Verbinden".
